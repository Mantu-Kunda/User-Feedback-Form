# User Feedback Form Application

A Java Servlet-based web application developed using Eclipse IDE and Apache Tomcat 11.

## Features

- Responsive feedback form
- Name, Email, and Feedback fields
- GET and POST request handling
- Dynamic confirmation page
- HTML input escaping for safer output
- Submit Another Feedback option

## Technologies

- HTML5
- CSS3
- Java
- Jakarta Servlet
- Apache Tomcat 11
- Eclipse IDE

## How to Run

1. Install Eclipse IDE with Enterprise Java support.
2. Configure Apache Tomcat 11.
3. Import the project into Eclipse.
4. Configure the Tomcat 11 target runtime.
5. Run the project on the server.
6. Open:

`http://localhost:8080/UserFeedbackApp/`

## Learning Outcomes

- Understanding Java Servlet lifecycle and request handling.
- Implementing HTTP GET and POST.
- Connecting an HTML frontend with Java.
- Deploying Java web applications using Tomcat.

## Note

This application demonstrates feedback processing. Submitted feedback is not permanently stored.
